# Installation / Instalación / Установка

## English

1. Download the two **ready-to-import** assets from the [release](https://github.com/SidorovichsWork/echo-anomaly-android/releases/tag/v0.8.1): `Echo_0.8.1_Standalone.zip` and `MCM_Mobile_Compatibility_1.0.0.zip`. No PC or Python is required.
2. Install original **MCM 1.7.2fix** separately. This fix does not contain MCM; do not assume newer MCM releases are identical.
3. Deactivate slow motion, save and close Anomaly completely before changing mods.
4. Disable original Slow Motion/SlowMoMod, ALL older Echo adaptations, `Echo_Icono_Mobile_Fix`, and the old `Correccion_MCM_Teclado_Mobile` full-file fix. Keep original MCM and unrelated required weapon fixes enabled.
5. Import `MCM_Mobile_Compatibility_1.0.0.zip` into Sidorovich's Mod Manager; select **gamedata** and enable it after MCM.
6. Import `Echo_0.8.1_Standalone.zip`; select **gamedata** and enable it after any mods replacing the equipment icon atlas or Sakharov trade configuration. Resolve or merge conflicts instead of enabling older Echo patches too.
7. Restart Anomaly. Open MCM → **Echo Resonance Regulator**. Load a save, buy the device from **Professor Sakharov** or press the MCM grant button, then assign it to an existing medicine/food quick slot. Use once for ON, again for OFF.
8. Default overload is **8 continuous seconds OR 4 activations in 30 seconds**. Recovery is **20 seconds after the last trigger**. Previous MCM settings remain saved; change a retained 15-second threshold manually if needed.

**Important:** do not load a save containing the device while Echo is disabled. The new MCM shim replaces only our older compatibility fix, not original MCM. MCM need not be reinstalled if disabling the old patch correctly restores its original script. If the old faction icon remains, close the game and regenerate only `appdata/ui_cache/ui_ui_icon_equipment.dds`; do not delete saves or the game folder. The common atlas is based on the tested Stalker Mobile installation and may conflict with icon packs. No new game is normally required for existing Echo saves.

## Español

1. Descarga los dos ZIP **listos para importar** de la [publicación](https://github.com/SidorovichsWork/echo-anomaly-android/releases/tag/v0.8.1). **No necesitas PC ni Python.**
2. Instala **MCM 1.7.2fix original** por separado. Nuestro fix no lo incluye; otras versiones requieren pruebas.
3. Desactiva la cámara lenta, guarda y cierra completamente Anomaly antes de cambiar mods.
4. Desactiva Slow Motion/SlowMoMod original, todas las versiones anteriores de Eco, `Echo_Icono_Mobile_Fix` y el antiguo `Correccion_MCM_Teclado_Mobile` que reemplazaba el archivo completo. Mantén MCM original y las correcciones de armas que necesites.
5. Importa `MCM_Mobile_Compatibility_1.0.0.zip` en el gestor; selecciona **gamedata** y actívalo después de MCM.
6. Importa `Echo_0.8.1_Standalone.zip`, selecciona **gamedata** y colócalo después de mods que reemplacen la hoja de iconos o el comercio de Sakharov. Combina los cambios si hay conflictos; no actives además parches antiguos de Eco.
7. Reinicia. En MCM abre **Regulador de resonancia «Eco»**. Dentro de una partida cómpralo a **Sakharov** u obténlo desde MCM y asígnalo a un acceso rápido de medicina/comida. Un uso activa; el siguiente desactiva.
8. Sobrecarga: **8 segundos seguidos O 4 activaciones en 30 segundos**. Recuperación: **20 segundos tras el último disparador**. Si MCM conserva el ajuste antiguo de 15 segundos, cámbialo manualmente a 8.

No cargues una partida que contenga el aparato con Eco desactivado. El nuevo fix sustituye nuestra corrección anterior, **no MCM**. Si desactivar el fix antiguo restaura MCM correctamente, no hace falta reinstalarlo. Si persiste el icono de facción, cierra el juego y regenera únicamente `appdata/ui_cache/ui_ui_icon_equipment.dds`; no borres partidas ni toda la carpeta del juego. Otros packs de iconos pueden necesitar una combinación de cambios. Tus partidas anteriores de Eco normalmente no requieren empezar de nuevo.

## Русский

1. Скачайте два **готовых к импорту ZIP** из [релиза](https://github.com/SidorovichsWork/echo-anomaly-android/releases/tag/v0.8.1). **ПК и Python не нужны.**
2. Отдельно установите исходный **MCM 1.7.2fix**. Исправление не включает MCM; другие версии требуют проверки.
3. Выключите замедление, сохранитесь и полностью закройте Anomaly перед изменением модов.
4. Отключите исходный Slow Motion/SlowMoMod, старые версии Echo, отдельный `Echo_Icono_Mobile_Fix` и старую полную замену `Correccion_MCM_Teclado_Mobile`. Оставьте MCM и нужные вашей сборке исправления оружия включёнными.
5. Импортируйте `MCM_Mobile_Compatibility_1.0.0.zip`, выберите **gamedata**, включите после MCM.
6. Импортируйте `Echo_0.8.1_Standalone.zip`, выберите **gamedata**, загрузите после замен общей таблицы значков или торговли Сахарова. При конфликтах объедините изменения; старые патчи Echo дополнительно не включайте.
7. Перезапустите игру. В MCM откройте **Регулятор резонанса «Эхо»**. В загруженной игре купите прибор у **Сахарова** или получите через MCM, назначьте в быстрый слот лекарств/еды. Первое использование включает, повторное выключает.
8. Перегрузка: **8 секунд непрерывной работы ИЛИ 4 включения за 30 секунд**. Восстановление: **20 секунд после последнего срабатывания**. Если MCM сохранил прежние 15 секунд, вручную установите 8.

Не загружайте сохранение с прибором при отключённом Echo. Новый патч заменяет только наше старое исправление, **не MCM**. Если отключение старого патча корректно восстановило MCM, переустанавливать его не нужно. Если остался старый значок, закройте игру и обновите только `appdata/ui_cache/ui_ui_icon_equipment.dds`; сохранения и папку игры не удаляйте. Другие наборы значков могут требовать объединения. Для существующих сохранений Echo новая игра обычно не нужна.
