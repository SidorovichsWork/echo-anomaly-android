# Credits and asset provenance

Echo 0.8.1 — Sidorovich's Workshop

Based on / inspired by Bullet Time Enhanced by pitAlex, itself based on exDeMODER's
original Legend Returns skills script:
https://www.moddb.com/mods/stalker-anomaly/addons/bullet-time-enhanced
The original addon's audio and keyboard-menu XML are NOT included.
This public build uses two newly synthesized electronic sounds by this project.

MCM by RavenAscendant, Tronex and contributors is a separate requirement:
https://www.moddb.com/mods/stalker-anomaly/addons/anomaly-mod-configuration-menu
Our standalone compatibility shim does not redistribute ui_mcm.script or MCM.

Echo is a fan-created modification for S.T.A.L.K.E.R. games, developed and owned
by GSC Game World. Echo is not an official GSC product, has no affiliation with
GSC Game World, and is a derivative fan work based on the S.T.A.L.K.E.R. games.
Game icon assets remain their respective owners' work, not public-domain assets
or assets relicensed by Sidorovich's Workshop. The included atlas is modified only
in the region containing Echo's custom sprite. Other game files are not included.
The item uses an existing game world model; the custom picture is inventory art.
